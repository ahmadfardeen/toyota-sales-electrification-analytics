# Python Data Preparation & Analysis

This folder contains the Python notebooks used to prepare, validate, transform, and analyze the Toyota datasets before loading the analytical data into MySQL and Power BI.

## Notebooks

### sales_extraction.ipynb
Extracts Toyota sales, regional sales, electrified vehicle sales, production, and H1 2026 data from Toyota's official workbooks.

### toyotaxlsx_cleaning.ipynb
Cleans the Toyota vehicle specification dataset, filters relevant vehicle generations, standardizes fuel/powertrain categories, and produces the cleaned vehicle specification dataset.

### sales_analysis.ipynb
Performs analytical preparation and comparisons covering regional sales, electrification trends, powertrain mix, major model sales, vehicle specifications, and H1 2026 performance.
