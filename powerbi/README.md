# Power BI Dashboard

This folder contains the Power BI dashboard developed for the Toyota Sales & Electrification Analytics project.

## Dashboard

The dashboard covers:

- Global Sales
- Electrification
- Regional Market Analysis
- Product Explorer
- Production & Supply
- KPI tracking
- H1 2025 vs H1 2026 comparison

The dashboard uses MySQL as the analytical data source and DAX measures for KPI calculations and interactive analysis.
